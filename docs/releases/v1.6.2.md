# DouDuo 1.6.2 · 短视频自动画中画、评论发送更稳、设置页重排

这一版新增短视频自动画中画，重写了发评论的流程（等签名、身份验证、失败重发），设置页重新分组，另外修了私信、作者主页和界面模式切换的几处问题。包为**未签名 IPA**，需要自行签名安装。

## 新功能

### 短视频自动画中画
- 设置 →「播放与弹幕」新增「离开应用时自动画中画」，默认关闭。打开后，看短视频时回到主屏或切到别的 App，系统会把当前视频转成悬浮小窗（能否启动由系统决定）。（#60，感谢 @kikozheng27-creator）
- 打开这个开关后，前台长按加速仍然不断声；只在离开 App 进小窗的那一刻把声音交还给系统播放器，小窗里暂停/播放和声音保持一致。
- 清屏模式原有的画中画行为不变。

### 作者主页定位「刚刚看过」
- 看视频时点作者头像进主页，刚刚看的那条作品会标上「刚刚看过」并描边；不在第一页时会自动往下翻找到它。
- 那条作品不在屏幕上时，底部出现「定位到刚刚看过」，点一下滚过去。
- 从主页里点开别的作品看完返回，「刚刚看过」会换成最后看的那条。

### 设置页重新分组
- 设置分为 界面 / 播放与弹幕 / 推荐与内容 / 评论与私信 / 缓存与离线 / 账号 / 关于。
- 关掉「显示弹幕」后，弹幕密度和去重会变灰。
- 设置 →「关于」可以随时查看当前版本的更新内容；升级后第一次打开也会显示一次。

## 改进与修复

### 评论
- 刚打开 App 时后台签名还没准备好，这时点发送会提示「约 N 秒后再点发送」，准备好后提示「现在可以发送了」，打好的草稿保留。
- 抖音要求身份验证时会弹出官方验证页，通过后这条评论自动重发一次；取消或失败不会重发，草稿保留。
- 评论先显示在列表里，发送失败可以就地重发；草稿在本机保存 3 天。
- 评论被拦下时会实际向抖音核对登录状态，登录已失效就直接提示重新登录。
- 「用网页评论框发送」改为默认关闭（部分账号用它发送时会被抖音判为异常并顺带退出登录）。

### 信息与私信
- 聊天里点对方头像或昵称，打开 App 里的作者主页，不再跳到网页版主页。
- 浅色外观下私信输入框打字是黑色，不再白字看不见。
- 通知里点「回复」，直接打开那条视频的评论区并进入「回复 @某人」；回复发出后会到评论区核对，找不到就如实提示，不再报成功。
- 私聊里分享的视频卡用 App 自己的播放器打开；离开会话或关掉信息页时，聊天里的视频声音会停掉。
- 从信息里点开的视频刚起播就被暂停的问题已修复。

### 播放与界面
- 在设置里切换界面模式（如「经典」⇄「简洁」）后，回到首页视频能正常继续播放，不再卡在暂停。（#61，感谢 @kikozheng27-creator）
- 内屏横屏打开侧栏评论时，评论区不再是纯黑。
- 直播菜单里的「我的关注」「发现更多」点一次就生效。
- 模块菜单加回「信息」入口，顶栏信息图标恢复带「信息」二字。

### 登录
- 后台网页会拦下抖音网页自己发出的退出登录请求；登录被清掉时会弹提示，可以直接重新登录。

## 验证与仍需确认的边界

- 编译通过，`scripts/test_*` 58 个回归脚本全部通过。
- 自动画中画和界面模式切换后恢复播放，已在作者的 iPhone Duo 上装机确认；私信点头像、作者主页「刚刚看过」、浅色输入框已装机，但没有逐项确认；评论与登录相关的修复主要靠回归脚本和真机日志验证，没有逐项手动操作确认。
- 自动画中画「加速过后再切出 App」时声音交还系统播放器的时机依赖系统，个别情况下切出的瞬间可能断一下声。
- 自动画中画需要系统设置里允许画中画；系统拒绝启动小窗时，会按原来的策略暂停播放。
- 直播画中画（#59）不在这一版。
